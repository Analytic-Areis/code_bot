Engineering Methodology: From 16 Game Theories to Apex Dominance

Rather than jumping directly to an unverified machine learning architecture, our methodology followed a disciplined five-phase evolutionary lifecycle.

1
Phase 1 · Foundation

16 Game-Theoretic Primitives (Models 01–17)

Constructed standalone models embodying isolated principles: Bayesian search priors, Prize-Collecting Steiner Trees (PCST), Colonel Blotto multi-front breaching, Stackelberg expansion bursts, UCB1 multi-armed bandits, Isaacs differential games, and POMDP ghost reachability.

Outcome: Average pairwise win rate ~41.2%. Served as an exhaustive adversarial test suite.
2
Phase 2 · Reinforcement Learning

First-Generation RL Champion (Model 23)

Unified scoring weights into an evolvable cascade and optimized via self-play (1+λ)-ES over multi-seed simulations. Integrated point-reflection mirror spawn prior and 2-step tactical checks.

Outcome: 85.4% Win Rate. Defeated all 16 game-theoretic baselines; occasional edge losses to rusher bots.
3
Phase 3 · Adversarial Hardening

Grandmaster Champion (Model 25)

Engineered specifically to defeat Model 23 and all 22 preceding models simultaneously. Added Real Danger Pullback defense (BFS threat excess), adjacent general lock, dynamic Rusher/Turtle/Boomer adaptation, castle economics (kind=2 at d≥7), and Turn 800 deathtouch staging.

Outcome: 97.9% Win Rate (47/48 wins). Unbeatable against Models 01–22.
4
Phase 4 · Neural Exploration

Sub-150ms In-Match Neural Network (Model 26)

Implemented a literal 3-layer neural value network (16→32→16→1) in pure Python standard library with online TD(0) backprop running in ~0.09 ms. Identified crucial failure mode: raw uncalibrated neural signal was too large (±50 pts), overriding crisp tactical spearhead movement.

Outcome: 93.8% Win Rate (45/48 wins). Verified feasibility of in-match ML within latency budget.
5
Phase 5 · Apex Synthesis

Final Champion (Model 27)

Fuses M25's proven Grandmaster cascade with 4 calibrated ML improvements: (1) Top-10 1-ply Beam Search opponent rollout, (2) Additive clamped neural value head (±8.0 max), (3) Enhanced DAG frontline funnel (+30 pts to single spearhead), and (4) Dedicated Turn 720+ Deathtouch attack column.

Outcome: 98.0% Win Rate (49 Wins, 0 Losses, 1 Draw across 50 games). 4.51 ms peak latency. Undisputed #1!

Model 27 Internal Architecture: The 4 Strategic Superpowers

How Model 27 resolves moves within 4.51 ms under the Python 3.12 standard library constraint.

Superpower 1 · Search

Top-10 Beam Search with 1-Ply Opponent Sim

Evaluates all candidate moves with base heuristic, sorts the top 10, and forward-simulates the resulting board state. If the move allows an adjacent enemy to immediately recapture, a severe −85.0 penalty is applied. If it enables lethal decapitation next turn, a +2500.0 bonus is awarded.

Superpower 2 · Machine Learning

Additive Clamped Neural Value Head (±8.0)

Pure CPython 3-layer neural network (16→32→16→1) fed by 16 spatial features (target distance delta, army advantage tanh, frontier threat, mod-50 phase). The output is strictly clamped to [−8, +8] and added with weight 0.8 to fine-tune close decisions without overriding hard safety rules.

Superpower 3 · Logistics

Enhanced DAG Frontline Funnel

Scans for the single best friendly frontline tile (army ≥ 3 and minimum BFS distance to enemy general). All rear allied armies receive an aggressive inward flow bonus (+30.0 + army×0.3) toward this tile, turning scattered territory armies into an unstoppable battering ram.

Superpower 4 · Victory Condition

Turn 720+ Deathtouch Column Routing

At turn 720, the engine detects the upcoming Turn 800 Deathtouch singularity rule. It locates the largest allied stack within 15 tiles of the enemy general and actively builds an attack column along the shortest path, timing the assault to strike right as deathtouch goes active.
